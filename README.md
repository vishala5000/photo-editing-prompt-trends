# 📸 Photo Editing Prompt - Google Trends Finder

Auto-built Android app that fetches **Rising Queries** from Google Trends for the "Photo Editing Prompt" niche.

## ✨ Features
- 🌍 **Global** filter
- 📅 **Last Week** data
- 🎥 **YouTube** search trends integration
- 📋 **Copy All** to clipboard with one tap
- 🔄 Real-time pull-to-refresh
- 🔐 **100% Auto-signed APK** via GitHub Actions (no manual keystore needed!)

## 🚀 Build Status
GitHub Actions auto-builds and signs the APK on every push.
